# Community

cpp-linter is maintained by two volunteers, and all of it happens on GitHub.

[Open GitHub Discussions](https://github.com/cpp-linter/cpp-linter/discussions){ .md-button .md-button--primary }

- **Questions and ideas:** [GitHub Discussions](https://github.com/cpp-linter/cpp-linter/discussions)
  has Q&A, Ideas and Show and tell categories.
- **Bugs and feature requests:** open an issue in the tool's own repository, for example
  [cpp-linter-action](https://github.com/cpp-linter/cpp-linter-action/issues) or
  [cpp-linter-hooks](https://github.com/cpp-linter/cpp-linter-hooks/issues).
- **Security problems:** don't open a public issue. Report them privately through GitHub on the
  affected repository, as the [security policy](https://github.com/cpp-linter/.github/blob/main/SECURITY.md)
  describes.
- **Contributing:** read the [contributing guide](https://github.com/cpp-linter/.github/blob/main/CONTRIBUTING.md)
  and the [code of conduct](https://github.com/cpp-linter/.github/blob/main/CODE_OF_CONDUCT.md).
- **Your project:** if it runs cpp-linter, [add it to the showcase](showcase.md#add-your-project).
- **Funding:** [sponsor cpp-linter](sponsor.md) through Open Collective.
